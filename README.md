# LT1, Part 2 - Circular Garden
## Description: 
The code asks for the radius of the garden and computes for the area, circumference, square root of the area, and the square root of the area rounded up and down using the math library.

## How To Run: 
The user inputs the radius of the garden and presses enter to show the calculated results.

## Input Needed: 
The radius

## Sample Output: 
Enter the radius of the garden: 6
Area of the garden: 113.10 square meters
Circumference of the garden: 37.70 meters
Square root of the area: 10.63
Area rounded down: 113 square meters
Area rounded up: 114 square meters

## Problem Identification:
Making a Python program that calculates the area, circumference, square root, and the rounded versions of the square root based on the radius entered by the user.

## Problem Decomposition:
- Ask the user to enter the radius of the garden.
- Calculate the area using A = πr².
- Calculate the circumference using C = 2πr.
- Calculate the square root of the calculated area.
- Look for the rounded down version of the area to the nearest whole number.
- Look for the rounded up version of the area to the nearest whole number.
- Show the calculated area, circumference, square root of the area, and the square root of the area rounded up and down.

## Pattern Recognition:
- Area = πr²
- Circumference = 2πr
- Square root = √A
- Round down = math.floor()
- Round up = math.ceil()
- input → process → output

## Data Representation:
Information - Data Type - Variable
- Radius - float - radius
- Area - float - A
- Circumference - float - C
- Square root - float - sqrt
- Area rounded down - int - lowsqrt
- Area rounded up - int - highsqrt

## Algorithm Development:
Algorithm:
- Start the program
- Import math library
- Ask user for the radius and accept it as a float
- Calculate the area
- Calculate the circumference
- Calculate the square root of the area
- Round down the area using
- Round up the area
- Display all results
- End the proogram
